# 未実装キャラの画像

ここに `キャラ名.webp`（`.png` `.jpg` も可）を置くと、くじで画像が表示されます。
ファイル名は下の名前と完全に同じにしてください（全角かっこも同じ）。画像がないキャラは名前カードで表示されます。
カード用は顔が中央に来るバストアップ（200:226、今は400×452で作成）にすると、ほかの生徒と並べたときに揃います。
詳細画面用に `portrait/キャラ名.webp`（全身の立ち絵そのまま）を置くと、そちらが優先して使われます（無ければカード用の画像を表示）。
