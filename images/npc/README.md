# 未実装キャラの画像

SchaleDB にいない（ストーリー等に登場のみの）キャラの画像です。キャラの定義は `index.html` の `NPCS` が唯一の場所で、ここには画像だけを置きます。

- `card/<ローマ字>.webp` … カード用。顔が中央に来るバストアップ、200:226（今は 400×452）
- `portrait/<ローマ字>.webp` … 詳細画面用。全身の立ち絵をトリミングせずに（今は高さ 1400px まで）
- `sources.csv` … 元画像（Blue Archive Wiki）のページ・URL・SHA256 の記録。アプリは読みません

## キャラを追加・画像を足すとき

1. `index.html` の `NPCS` に1行足す（`name` `school` など）。
2. 画像があれば `card/` と `portrait/` に同じファイル名（ローマ字小文字、例 `yume.webp`）で置き、その行に `img:"ファイル名（拡張子なし）"` と `src:"Wikiのファイル名"` を書く。`img` を書かなければ名前カードで表示されます。
3. 出典を `sources.csv` に1行足す。

SchaleDB に実装されると、同じ名前のキャラは自動で内蔵リストから外れます。SchaleDB 側の表記が違う場合は `aka:["SchaleDBでの名前"]` を書いてください。
